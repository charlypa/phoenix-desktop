- Wait for official v2 plugin (no ETA)
- Continue on Tauri 1.x
- **Effort:** N/A
- **Risk:** High (security updates will focus on 2.0)

**Decision Required:** Must be made before proceeding

## Key Breaking Changes to Address

### 1. Custom Protocol Handler (HIGH PRIORITY)

**Change:** Return type is now `Response` instead of `Result<Response>`

**Before:**
```rust
.register_uri_scheme_protocol("phtauri", |app, req| {
    Ok(response)  // ← Wrapped in Ok()
})
```

**After:**
```rust
.register_uri_scheme_protocol("phtauri", |app, req| {
    response  // ← Unwrapped
})
```

**Testing Required:** Verify asset loading works on all platforms

---

### 2. Path API (HIGH PRIORITY)

**Change:** `tauri::api::path::*` moved to `Manager::path()`

**Before:**
```rust
tauri::api::path::app_local_data_dir(&config)
```

**After:**
```rust
app.handle().path().app_local_data_dir()
```

**Testing Required:** Verify app data directory is correct on all platforms

---

### 3. Allowlist → Permissions (MEDIUM PRIORITY)

**Change:** Entire security model redesigned

**Migration:** Automated by `tauri migrate` command

**Manual Review Required:**
- Verify all needed permissions granted
- Check window-specific capabilities
- Test remote domain IPC access (healthData window)

---

### 4. Plugin Registration Order (HIGH PRIORITY)

**Change:** single-instance plugin MUST be registered first

**Before:**
```rust
.plugin(tauri_plugin_fs_extra::init())
.plugin(tauri_plugin_window_state::init())
.plugin(tauri_plugin_single_instance::init(|app, argv, cwd| {}))
```

**After:**
```rust
.plugin(tauri_plugin_single_instance::init(|app, argv, cwd| {
    // Add window focus logic
    let _ = app.get_webview_window("main")
        .expect("no main window")
        .set_focus();
}))
.plugin(tauri_plugin_window_state::init())
```

**Testing Required:** Verify single-instance prevention works

## Build Scripts Impact

### Current fs-extra Usage in JavaScript

**Location:** Build scripts only (not runtime)

**Functions Used:**
- `fsExtra.copy()` - Copy directories
- `fsExtra.pathExists()` - Check existence
- `fsExtra.remove()` - Delete directories

**Impact:** Low - can keep fs-extra in package.json for build scripts

**Alternative:** Use Node.js native APIs (requires Node 22.3.0+)
```javascript
import { cp, rm, access } from 'fs/promises';
await cp(src, dest, { recursive: true });
await rm(path, { recursive: true, force: true });
await access(path, constants.F_OK);
```
